# Coin Collector Obby

A small Roblox game defined entirely in Luau and synced into Roblox Studio
with [Rojo](https://rojo.space/). There's no binary `.rbxl` file to manage —
`GameSetup.server.lua` builds the whole map (spawn, obby platforms, coin
room, win pad) in code the moment the game starts, so the project is fully
reproducible from this repo.

## How it plays

1. Players spawn on a blue platform and climb a set of rising stepping-stone
   platforms with gaps between them.
2. At the top, a marble coin room holds 10 spinning gold coins in a ring.
   Touching a coin adds 1 to that player's `Coins` leaderstat and the coin
   respawns 5 seconds later.
3. A gold "win pad" sits in the middle of the coin room. Step on it after
   collecting 10 coins to trigger a "You win!" banner.
4. Falling off the course below y = -25 resets the player (health set to 0,
   so they respawn at the spawn point).

## Project layout

```
roblox-game/
  default.project.json                 - Rojo project definition
  src/
    ServerScriptService/
      Leaderstats.server.lua           - creates each player's Coins stat
      GameSetup.server.lua             - builds the map and runs game logic
    StarterPlayer/StarterPlayerScripts/
      CoinHud.client.lua               - coin counter + win banner UI
```

## Running it in Roblox Studio

1. Install [Rojo](https://rojo.space/docs/v7/getting-started/installation/)
   (the `rojo` CLI) and the matching Rojo plugin in Roblox Studio.
2. Open Roblox Studio and create a new place from the **Baseplate** template
   (or any empty place — the ground is generated by the script, so you don't
   need Studio's default baseplate part).
3. From this `roblox-game/` directory, start the Rojo server:
   ```
   rojo serve
   ```
4. In Studio, open the Rojo plugin panel and click **Connect**.
5. Press **Play**. `GameSetup.server.lua` builds the course automatically —
   climb the platforms, collect 10 coins, and step on the gold pad to win.

## Customizing

- `COINS_TO_WIN`, `COIN_COUNT`, `PLATFORM_COUNT`, and `FALL_RESET_HEIGHT` at
  the top of `GameSetup.server.lua` control the difficulty and length of the
  course.
- To add more obstacles, extend the platform-generation loop in
  `GameSetup.server.lua` with different shapes, moving parts, or hazards.
